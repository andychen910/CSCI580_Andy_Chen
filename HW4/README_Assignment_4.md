# CSCI 580 - Assignment 4: SA + GA

This project uses Simulated Annealing (SA) and a Genetic Algorithm (GA) to find shorter tours for a 40-city Traveling Salesman Problem.

## How to run
1. Open `Assignment_4_Completed.ipynb` in Google Colab.
2. Click Runtime > Run all.
3. Check the printed results and graphs under the cells.
4. The PDF report explains the results and the Part 6 questions.

No extra data files are needed. The code uses Python and matplotlib.

## Results from my saved notebook
- Nearest Neighbor: 6.0214
- SA: 5.3626 (10.94% shorter than NN)
- GA: 5.3672 (10.86% shorter than NN)

The values are reproducible with the seeds in the notebook. Part 7 extra credit was not done.
